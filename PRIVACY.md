# Privacy notice

Zovo Recorder records only after a user starts a capture and chooses a Chrome capture surface. Video, audio, drawings, annotations, chapter markers, and recovery chunks are processed and stored locally in the browser unless the user explicitly downloads or shares a result.

The store build contacts the Zovo Supabase function only when a user submits a license key for verification. The request contains the entered license key and the product identifier `recorder`. The public anonymous client key authorizes access to that verification function; privileged database keys are not included.

The extension does not sell personal data, run advertising, or transmit recorded video/audio to Zovo by default. Diagnostic downloads are created locally and sent only if the user chooses to share them.

Website privacy policy: https://zovo.one/privacy
